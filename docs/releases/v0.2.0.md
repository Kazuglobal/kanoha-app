# Release Notes v0.2.0

## 概要
本リリースでは、子どもの学習体験（UI/UX）の抜本的な改善、国語・算数の全単元カリキュラムの拡充、手書き回答時の自動答え合わせ、およびAIヒント再生成時のエラー解消を実施しました。

## 主な変更点

### 1. 「ヒントをもっと簡単に」の安定化
- `/api/ai/generate-hints` エンドポイントのリクエストバリデーションを堅牢化し、`sessionId` や `childId` が `null` または未指定の場合でも 400 エラーにならず安全にフォールバック。
- カリキュラムバンクの全問題に対応し、未知の問題IDでも安全なフォールバックヒントを提供して 404 エラーを解消。
- ヒントをまだ開いていない段階で「もっと かんたんに」を押した場合でも、自動的にやさしいヒント1を表示するよう UX を最適化。

### 2. 国語・算数の全単元カリキュラム拡充＆ステージマップ
- 小学2年生の全単元（算数11単元・国語5単元）を網羅したカリキュラムバンクを実装。
- ホーム画面にビジュアル豊かなステージマップを新設。
- 問題正解後に「つぎの もんだいへ すすむ！」ボタンから次の単元・問題へスムーズに進める連続学習フローを導入。

### 3. スクロールレスUI＆ゲーム風デザイン
- 画面スクロールを不要にする2カラム構成のゲーム風レイアウトに全面刷新。
- キャラクターコーチ、手書きモーダル、トイ風テンキーを新設。
- 手書き完了時に「これで こたえる」を押すだけで、即座に正誤判定（答え合わせ）が自動実行される連携を実装。

### 4. 品質・テスト
- 全 73 テストファイル / 467 テストを 100% 合格。
- TypeScript 型チェック（`tsc --noEmit`）エラー 0 件。
- Cloudflare Workers 本番環境へデプロイ済み。
